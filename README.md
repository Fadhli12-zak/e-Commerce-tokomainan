# Toy Store E-Commerce Website

A front-end e-commerce website prototype for a toy store built with **HTML**, **CSS**, and **JavaScript**.

## Live Demo
<https://fadhli12-zak.github.io/e-Commerce-tokomainan/>

## Overview
This project simulates an online toy store experience with product listing pages, navigation menus, blog pages, contact pages, and simple storefront interactions.

## Features
- Home page with promotional banner sections
- Product listing and storefront layout
- Shop, blog, about, contact, and cart pages
- Static product detail and navigation flow
- Responsive front-end styling

## Tech Stack
- HTML
- CSS
- JavaScript

## Project Goal
This project was built to practice front-end web development and multi-page website structure in an e-commerce context.
